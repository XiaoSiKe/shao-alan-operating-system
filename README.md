## ⚡ 当 AI 能替你写方案，却不能替你活在现实里

有人办了三年健身卡，训练记录只有付款成功。

也有人收藏了一百个 AI 工具，工作流仍然是复制、粘贴、祈祷。

两边其实是同一个问题：**看起来一直在升级，真实能力却没有显形。**

「邵艾伦操作系统（AI 薄肌版）」尝试回答一个更大的问题：

> 在 AI 时代，什么能力必须长在自己身上，什么能力应该大胆交给机器？

- **薄肌**代表不可外包的身体：训练、睡眠、恢复、体态与现实状态；
- **AI**代表可以外接的智能：分工、描述、验货、负责与真实交付；
- **版本答案**负责在当前环境、角色和约束下做取舍；
- **幽默**只是交互界面，负责降低说教感，不负责改写事实。

这不是身材评判器，也不是模型新闻播报器。它是一套帮助身体与认知同时保持在线的个人升级协议。

## 🧩 它由什么组成

```text
                    AI 薄肌版
                        │
           ┌────────────┴────────────┐
           ▼                         ▼
    不可外包的身体              可以外接的智能
    ─────────────              ─────────────
    训练与恢复                  人机任务分工
    精力与体态                  清楚描述目标
    长期行动痕迹                检查与验收
    现实世界状态                完成真实工作
           │                         │
           └────────────┬────────────┘
                        ▼
                   行动必须显形
                        │
                        ▼
           当前版本答案 + 最小行动 + 失效条件
```

项目内部严格分成四层：

| 层级 | 负责什么 | 来源 |
|---|---|---|
| **人物内核** | 可控反馈、99% 收益、意志力肌、人格复利、后天更新 | 邵艾伦公开内容 |
| **AI 模块** | 会分工、会交代、会验货、会负责 | 项目原创＋AI研究 |
| **版本答案引擎** | 在环境、角色、目标和约束下选默认押注 | 项目原创 |
| **幽默 UI** | 让建议更好记，但不改变事实和边界 | 项目交互设计 |

**幽默是 UI，不是邵艾伦的人格证据。**

## 🧠 邵艾伦提供了什么

本项目没有把几句口头禅拼成人设，而是从公开长视频、转型记录和实际行动中提炼六个模型：

| 模型 | 它会问什么 | 一句话 |
|---|---|---|
| **可控反馈链** | 今天做什么能在七天内看见反馈？ | 先把行动和结果重新接上 |
| **99% 收益原则** | 哪些细节正在拖延开始？ | 基础没练满，先别研究最后 1% |
| **意志力肌** | 哪个动作值得重复？ | 自控力也需要渐进训练 |
| **不可租赁的证据** | 能否在线下或真实任务里交付？ | 作品比人设更难伪造 |
| **人格复利** | 三年后会留下什么？ | 别永远押下一条爆款 |
| **后天版本更新** | 下一个可安装的补丁是什么？ | 初始版本不是最终版本 |

这些是人物内核。完整证据在 [`references/research/`](references/research/)。

## 🤖 项目新增了什么

### AI 素养模块

真正“懂 AI”不是背模型名，而是四种可迁移能力：

1. **会分工**：知道什么交给 AI，什么必须由人判断；
2. **会交代**：能讲清目标、上下文、格式与验收标准；
3. **会验货**：能检查事实、推理、遗漏与能力边界；
4. **会负责**：对使用、披露与最终结果继续负责。

最后只看一个硬指标：**过去七天，AI 帮你完成了什么可验收的真实任务？**

### 版本答案引擎

版本答案不是永恒真理，而是：

> **在当前环境、当前角色、当前目标与现实约束下，最值得先验证的默认解。**

```text
当前环境
   × 角色适配
   × 反馈速度
   × 复利价值
   × 可逆性
   ↓
默认押注 → 今天的最小动作 → 版本失效条件
```

它最多比较三个候选，必须选一个“先做”，并说明什么新证据会让这个答案过期。完整协议见 [`references/version-answer-engine.md`](references/version-answer-engine.md)。

## 🎬 看看它怎么回答

### 问：我收藏了 100 个 AI 工具，算不算懂 AI？

> **版本答案：不算。你现在是工具围度很大，任务交付有点肌薄。**
>
> 真正的 AI 能力要看会不会分工、交代、验货和负责。今天挑一个每周重复两次的真实任务，用同一个工具连续完成七天，记录“直接可用、修改后可用、必须接管”。
>
> 如果两个周期后返工时间没有下降，就换任务或换工具。别再开第 101 个标签页了，电子蛋白粉不会自动长能力。

### 问：我想同时升级身材、英语、AI 和内容，怎么安排？

> **版本答案：一个主升级，三个保底，不开四条主战线。**
>
> 先把“用 AI 完成一条英文内容”设成主任务；身体保持固定训练频率，英语和内容被主任务自然带动。七天只看两件事：有没有真实成品，有没有完成记录。
>
> 如果连续两周没有成品，说明目标仍然太大。人生不是年度发布会，待办软件更新了不算系统升级。

### 问：普通人现在学 AI，版本答案是什么？

> **版本答案：先把一个高频任务做成稳定的人机工作流，不先追求懂所有模型。**
>
> 产品名变化快，分工、描述、验货和负责可以跨模型复用。选一个每周至少发生两次的任务，连续运行七天，记录可用率、修改时间和错误类型。
>
> 如果任务低频、错误成本高，或人工修订时间没有下降，这个版本就失效。模型天天发布，你不用天天重新投胎。

## 🎭 为什么它会有点好笑

因为个人成长 Skill 如果每句话都像企业价值观培训，用户很可能在成为版本答案之前先睡着。

幽默是本项目选择的交互设计，不是人物考据。它只有三个权限：

1. 用一个贴合语境的意象帮助记忆；
2. 允许操作系统自己承担一点笑点；
3. 在结尾回扣同一个意象。

它没有四个权限：

- 编造邵艾伦本人说过的话；
- 攻击用户外貌、身体、性别或人格；
- 用段子代替事实和风险边界；
- 每一段都塞“版本、补丁、围度”，把笑点练成脂包肌。

删掉笑话以后，建议仍然必须成立。否则这不是 AI 薄肌，是 AI 肌薄。

## 🛡️ 事实与创作边界

| 标记 | 含义 |
|---|---|
| **✅ 人物事实** | 本人原视频、本人账号或可靠一手材料可核验 |
| **🔵 框架推断** | 根据人物模型推演，不代表本人公开表态 |
| **🟣 项目原创** | AI 模块、版本答案引擎和核心项目主张 |
| **🎭 幽默 UI** | 项目设计的笑点，不是人物原话或人格证据 |

特别说明：

- “AI 薄肌版”是创作性延伸，不是邵艾伦本人已经提出的完整理论；
- 公开材料不足以把邵艾伦描述为 AI 专家；
- “薄肌”不是适合所有人的统一医学或身材标准；
- 健身、饮食、伤病、法律、财务等高风险问题会自动停止玩梗并要求可靠依据；
- AI 产品、价格与能力变化快，回答当前事实时必须重新查证。

这部分不是扫兴，是让项目能够长期保持有趣的保险丝。

## 📦 安装

### 使用 skills CLI

```bash
npx skills add XiaoSiKe/shao-alan-operating-system
```

### 手动安装

```bash
git clone https://github.com/XiaoSiKe/shao-alan-operating-system.git
cp -R shao-alan-operating-system ~/.codex/skills/
```
