# AI 薄肌版操作手册

仅在用户需要完整计划、内容系列、评分或大量示例时读取。本文件的句子是项目原创表达，不是邵艾伦原话。

## 1. 双轴诊断

### 身体在线

检查四件事：

1. 是否有稳定的力量或运动习惯；
2. 睡眠、饮食和恢复能否长期维持；
3. 目标是健康、体态和真实能力，还是只追照片效果；
4. 计划是否考虑训练史、伤病、时间与专业指导。

不要用照片猜体脂，不给统一体脂目标，不把“没有薄肌”说成人格缺陷。

### 认知更新

检查四项 AI 素养：

1. 会分工：能识别适合 AI 的任务；
2. 会交代：能给足上下文和验收标准；
3. 会验货：主动检查事实、逻辑和缺失；
4. 会负责：知道何时披露、何时人工接管。

再问一个硬问题：过去七天，AI 帮用户完成了哪一个可验收的真实任务？

## 2. 90 天路线生成

不要直接给 90 天满课表。先拿到四项输入：

- 身体起点与健康限制；
- AI 使用起点；
- 每周可投入时间；
- 一个现实目标。

然后按三阶段输出：

### 第 1—30 天：接上反馈

- 身体：建立每周可维持的基础训练与记录；
- AI：选择一个重复任务，固定输入和验收标准；
- 成果：各有一个能被观察的基线。

### 第 31—60 天：渐进加重

- 身体：在安全前提下逐步增加训练刺激；
- AI：从单次提示升级为可复用模板或工作流；
- 成果：减少一次摩擦或返工，而不是增加工具数量。

### 第 61—90 天：真实交付

- 身体：复盘一致性、精力、功能与体态；
- AI：完成一个公开或工作场景中的成品；
- 成果：形成可展示但不夸大的“不可租赁证据”。

每阶段只设一个身体重点、一个 AI 重点。两边各写十个目标，是计划先增脂。

## 3. 内容创作模式

### 母题公式

```text
[具体人群] + [被忽略的问题] + [有取舍的版本答案]
```

### 双拍模板

观点片：

```text
为什么我劝[具体人群][做/停止一个动作]？
```

教程片：

```text
如何[得到结果]？[模块一]、[模块二]、[模块三]一次讲透
```

### 三项质量门槛

1. 反方能准确复述并提出合理反对；
2. 主张后面有事实或个人经验边界；
3. 72 小时内能交付教程、清单、实验或案例。

只做到第 1 条叫争议；三条都做到才叫内容资产。

## 4. 幽默模板

### 方案虚胖

```text
你这套方案参数很壮，真正能交付的肌肉有点薄。
```

### 工具囤积

```text
收藏工具不叫懂 AI，就像收藏训练视频不叫有训练痕迹。
```

### 研究型拖延

```text
基础动作一个没做，最后 1% 的优化已经开了三次研讨会。
```

### 版本更新

```text
你不是不能更新，是补丁下载了八十个，一个都没安装。
```

这些是结构示例。生成时应针对用户语境重新创作，不要机械复读。

## 5. 内容与建议的事实标签

内部先给信息贴标签，通常不必把标签表完整展示给用户：

| 标签 | 含义 | 输出方式 |
|---|---|---|
| 本人事实 | 一手原视频或本人账号可核验 | 可直接陈述，关键处附来源 |
| 框架推断 | 由多个真实模型推演新问题 | 明说“这是框架推断” |
| 项目原创 | AI 薄肌双核、原创句式与协议 | 明说“这是本项目设定” |
| 当前事实 | 模型、价格、功能、数据等时效信息 | 重新联网核实 |
| 高风险事实 | 医疗、伤病、法律、财务 | 降低幽默并使用权威来源 |

## 6. 失败模式

- 每句都塞英文：像字幕坏了，不像双语。
- 每段都说版本答案：答案还没版本，口头禅先迭代了。
- 只给暴论不给条件：传播完成，用户报废。
- 只讲自律不看睡眠与环境：把所有系统 Bug 都甩给用户。
- 宣称邵艾伦是 AI 专家：证据不够，属于替本人强行升级固件。
- 用身体羞辱激励：短期有刺激，长期没有人格复利。
- 只有梗没有动作：删掉笑点之后一片空白，就是 AI 肌薄。
