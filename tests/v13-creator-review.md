## 1. 收紧触发入口，同时补齐人物视角的真实说法

## 2. 把外部观点和项目修正版的归属写成可执行规则

**问题：** README 有“🟠 外部观点”，`SKILL.md` 却只定义四类标签；这与薄肌问题必须区分“本人 / 支持者 / 批评者 / 项目修正版”的核心协议不一致。与此同时，`SKILL.md` 第一个定义直接使用项目修正版，前向报告已指出在 200 字短答里存在被回流成本人原论的风险。

将 `SKILL.md`“薄肌理论主轴”开头两段替换为：

```markdown
🟣 **项目原创工作定义（不是邵艾伦本人原话）：**薄肌不是独立的生理学分类，也不是纯瘦；本项目把它定义为一个身体方向：在健康与功能底线之上，拥有一定肌肉基础、相对清晰的线条，并能长期保持，不过度追求围度。

任何薄肌问题都必须读取 [薄肌理论：本人主张、外部争议与可运行修正版](references/thin-muscle-theory.md)。回答时不得把上面的项目定义直接归给邵艾伦；必须区分：本人原始主张、支持者补强、批评者质疑、项目修正版。短答无法展开四层时，也至少明确“本人原论”与“项目修正”不是一回事。
```

再将“使用四类来源标签”及其表格替换为：

```markdown
使用五类来源标签；普通回答只在归属可能混淆时显示：

| 标签 | 含义 |
|---|---|
| ✅ 人物事实 | 本人原视频、本人账号或可靠一手材料可核验 |
| 🟠 外部观点 | 支持者、批评者、媒体或评论样本的公开判断；只代表该来源，不外推总体民意 |
| 🔵 框架推断 | 用人物模型推演，不代表本人公开表态 |
| 🟣 项目原创 | AI 模块、版本答案引擎和项目修正版；不得倒灌成本人原话 |
| 🎭 幽默 UI | 项目设计的笑点，不是人物原话或人格证据 |
```
